Dataset for Option 1 · ↗ · ⤓

You are interested in people’s ability to ignore irrelevant visual information when under time pressure. To this end, you have run an experiment in which you presented participants with color words written in various ink colors and asked them to report the ink color of each word as quickly as possible. There are two conditions in the experiment: First, a congruent condition in which the word presented is written in the same color ink, for example, the word “red” is written in red (red). Second is the incongruent condition, in which the word presented is written in different colored ink, for example, the word “red” written in blue (red). The stimuli in the study consisted of 4 colors (red, blue, yellow and green) that could be used for both the written words and the ink. Each stimulus was presented 3 times in the congruent condition and 3 times in the incongruent condition (once in each color different from the word). For each presentation of a stimulus, the experimenters recorded the time it took the participant to verbally produce the color of ink that the word was written in. So when presented with the word “red” written in blue ink (red), the participant should say “blue.”

You have hypothesized that it takes additional effort for people to inhibit the irrelevant perceptual information from the obligatory reading of the color word, and therefore that the mean response time in the incongruent condition will be higher than in the congruent condition. You should test this hypothesis using the data provided and produce an appropriate effect size estimate. As usual, make sure you plot and discuss the raw data and relevant data summaries. Additionally, you have a collaborator who would like to perform a replication of the study. For their power analysis they want to be conservative and use the smallest effect size consistent with your data. Based on the limits of your confidence interval for the effect of congruency on reaction time, make a recommendation for the effect size they should use in their power analysis.

Dataset for Option 2 · ↗ · ⤓

You are studying how human memory declines as we age. You have data from a longitudinal study that tested participants’ ability to remember a list of words at various points in their life: Participants were tested once at 25 years of age and again at 65 years of age. In the experiment, you presented participants with a list of 15 words that they must memorize. 24 hours later they are brought back to the lab and asked to reproduce from memory the entire list of words. If a word is recalled it is recorded as Recalled=1 and if not it is recorded as Recalled=0.

You have hypothesized that the ability to recall long lists of items gets worse as we age, which would result in fewer words being recalled on average at age 65 than at age 25. You should test this hypothesis using the data provided and produce an appropriate effect size estimate. As usual, make sure you plot and discuss the raw data and relevant data summaries. Additionally, you have a collaborator who would like to perform a replication of the study. For their power analysis they want to be conservative and use the smallest effect size consistent with your data. Based on the limits of your confidence interval for the effect of aging on recall performance, make a recommendation for the effect size they should use in their power analysis.

Because there are multiple rows per participant per condition/Visit (condition for Stroop Effect, Visit for Memory Decline), before using pivot_wider(), you must first transform the dataframe into having 1 row per condition/Visit for each participant (2 rows in total for each participant). You can do this using a combination of group_by() and summarize(), and combine those multiple rows into a single row using mean() or sum().

You want one row per participant per condition/Visit. So which variables do you include in group_by()?

After transforming the dataframe, you can then use pivot_wider(). If your table is looking odd, double check to make sure you used the new variable you created in the previous step, instead of the old one.
