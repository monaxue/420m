Pipes: %>%

  • Applies functions to data tables
  • The following are equivalent
    • head(table_name)
    • table_name %>% head()
  • Why use pipes?
    • They allow you to chain multiple functions together
    • table_name %>% mutate(...) %>% head()

  • ❓ Compare summarize() with mutate(). How do they differ?
    • summarize() deletes rows with missing data
    • summarize() adds up all the rows so only one is left
    • summarize() aggregates the values and removes redundant rows (correct)

group_by()

  • We can use pipes to add the group_by() before using summarize.
  • table_name %>% group_by(sex) %>% summarize(Mean=mean(washes))
  • You can group by multiple groups, like so: group_by(column1, column2, column3)
# A tibble: 2 × 2
  sex    Mean
  <chr> <dbl>
1 F      35.6
2 M      34.4
  • ❓ Compare summarize() with group_by() to the to the previous version without it. What’s the difference?
    • summarize() alone produces one summary for the full dataset, while group_by() followed by summarize() produces a separate summary for each group. (correct)
    • group_by() sorts the dataset, and summarize() then reports the first value in each group.
    • group_by() removes duplicate rows before summarize() calculates the mean.

Descriptive vs. inferential statistics

Descriptive vs. inferential statistics

  • Descriptive
    • Visualize the general shape, center, and spread of the sample
    • “See the forest, but not the trees”
  • Inferential
    • Make inferences about the true population means

Descriptive statistics

  • Larger trends in the data, without making claims about the true population values.
  • “Ambiguous thinking”
    • Shape: Is it normal? Symmentrical? Skewed (rarer than you think!)? Bimodal?
    • Center ~ Sample mean
    • Spread ~ Sample SD

“Ambiguous thinking”

Interpreting descriptive statistics

  1. Shape (skew)
    • All three samples are somewhat bell shaped. There is no clear skew in any of the plots.
  2. Spread
    • All three samples have similar similar widths,. None are clearly wider than the other.
  3. Center (optional)
    • In all three samples, the score is centered at around 10.
    • Note: Performance score, not just performance.

❓ Which interpretation is the best?

  • Histograms
  • Answer options
  • Explanations
  1. Both plots are bell shaped, with the second plot being slightly more skewed. The first plot is slightly narrower than the second. The score is centered at around 5 for the first plot, whereas it is centered at around 7 for the second plot. (correct)
  2. The second plot is significantly more skewed than the first plot. It is also significantly wider. Both plots are bell shaped. Memory levels for the second group is higher, with a mean of 7, than for the first group, with a mean of 5.
  3. Both plots are rather bell shaped, though the second plot may be more skewed and is slightly wider than the first plot. The memory levels for the second group is higher than for the first group, at about 7, whereas the first group has a lower memory level, at about 5.
  4. Both plots are bell shaped. The second plot is slightly wider and slightly more skewed than the first plot. (correct)
  • 1 includes talking about the shape, spread, and center, without making claims about the popultion.
  • 2 is wrong because it uses the word “significant”, which implies a population level conclusion.
  • 3 is wrong because it makes a strong statement about a group difference. Without specifying that the difference is in the the score, not just memory levels, it doesn’t specify that it is only in these samples.
  • 4 avoids any issues with interpreting the “center” by not talking about it at all. Remember that in this class, describing the “center” is optional for descriptive plots.

Inferential statistics

  • What can we infer about the population from the sample?

  • Guessing game: I have take a random sample from either Population A or Population B. Which population does this random sample come from?
    • “Population” = The true distribution

I took a second random sample from either Population A or Population B. Which distribution does this random sample come from?

Statistical tests must be used

  • It can be hard to tell which population the sample came from!
  • Instead of asking, “do we know for sure which distribution the sample comes from?”, can we instead ask “what is the probability that the sample comes from A or B?”
    • Kind of. There isn’t a way to exactly calculate the probability, but we can still capture this intution with the idea of “confidence”.
  • We must use some sort of test, like confidence intervals or t-tests, to infer something about the true population (more on CIs next week)
