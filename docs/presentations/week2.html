RMarkdown review

❓ What’s the difference between .r and .Rmd?

  • They are the same file types, but just different names (correct)
  • .r can only take R code whereas .Rmd combines the functionality of document editing and R code
  • You can use more complex R code in .Rmd than in .r files

❓ How do you create a title named “Title”?

  • #Title
  • # Title (correct)
  • **Title**
  • Either #Title or # Title

❓ How do you write a comment?

  • #Comment
  • # Comment
  • **Comment**
  • Either #Comment or # Comment (correct)

❓ What’s the main difference between a title and a comment?

  • A title is outside a code block whereas a comment is inside a code block (correct)
  • A title is inside a code block whereas a comment is outside a code block
  • People use different terms, but they are actually the same thing because they both use #

❓ What is a code chunk and how do you create one?

  • A code block is any section in an Rmd file. As long as you are in a Rmd file, you are in a code block.
  • A code block is any section in the Rmd file that outputs code. You create it by denoting it with **Code block**.
  • A code block is any section in the Rmd file that you can write code in. You create it by denoting it with **Code block**.
  • A code block is any section that you can write code in. You create it by wrapping code with ```{r} ```. (correct)

Introduction to ggplot()

ggplot layers

  • ggplot is a package for making plots
  • ggplot uses layers. Each layer is added with the + symbol
    • Layer1 + Layer2 + Layer3
    • Every layer adds something new to the plot

Layer 1: basic info

  1. Specify the data table
  2. Specify the x and y variables in aes()
ggplot(table_name, aes(x=column1, y=column2))

Layer 2: actual plot

  • geom_histogram() adds histogram layer
  • geom_point() adds scatter plot layer
# Histogram
ggplot(...) + geom_histogram()
# Scatter plot
ggplot(...) + geom_point()

❓ Which produces a valid histogram?

  • ggplot(table_name, x=column1, y=count1) + geom_histogram()
  • ggplot(aes(x=column1)) + geom_histogram()
  • ggplot(table_name, aes(x=column1)) + geom_histogram() (correct)
  • ggplot(table_name, aes(x=column1, y=column2)) + geom_histogram()
    • Histograms do not plot a y variable, the only variable is x, on the y-axis shows the counts for x.
