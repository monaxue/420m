Vectors

This is how you create a vector. You use the notation c()

x <- c(a, "a")
y <- c(1, 2, 3)
z <- 1:3 # This is the same as y. The : indicates a vector from 1 to 3

To print the variable, simply run the name of the variable

x
[1] "1" "a"

Notice that without quotes, a refers to a variable and prints the number assigned to it (1), whereas with quotes, "a" prints out just the letter. When things are wrapped with quotes, they are called strings.

To choose a specific element of a vector, you can use []

x[2]
[1] "a"
y[3]
[1] 3
y[c(2, 3)]
[1] 2 3
y[1:2]
[1] 1 2

Vector examples

a <- 1 # assigns the number 1 to the variable `a`
b <- 1:3 # creates a list of numbers from 1 to 3 and assigns it to `b`
c <- c(3,4,5) # creates a list that includes 3, 4, 5 and assigns it to `c`
c[4] <- 6 # assigns the 4th element of `c` to the number 6, resulting in the list 3, 4, 5, 6
d <- c(b,c) # combines the lists b and c, producing the list 1, 2, 3, 3, 4, 5, 6, and assigns this to `d`
1 + 1
[1] 2

Adding a single number to a vector

y + 1 # Adds the single number to all elements in the vector
[1] 2 3 4

Adding a vector to a vector

y + z # Adds the 1st to the 1st, the 2nd to the 2nd, etc.
[1] 2 4 6
